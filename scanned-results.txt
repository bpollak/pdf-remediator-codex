Add the hidden structure (tags) screen readers need

The easiest way is to go back to the source file (Word, PowerPoint, Google Docs) and export it again as a tagged PDF. Otherwise, add tags in Acrobat Pro, including heading order, reading order and table structure.

Required before publishing. Tick this once you have made the fix.

Confirm the document language

The original PDF did not say what language it is in, so we set one. If it is wrong, set the language in the source file (in Word: Review → Language) and export again, or in Acrobat Pro under File → Properties → Advanced.
