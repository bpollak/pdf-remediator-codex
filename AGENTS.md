# Agent Instructions

## Deployment Workflow
- After completing each enhancement, commit the relevant changes and push them to GitHub so Vercel can pick up and deploy the update.
- Before pushing an enhancement, update the Release Notes in `lib/content/release-notes.ts` so the shipped changes are reflected in the app.
- Do not include unrelated modified or untracked files in those commits.
- If the user explicitly says not to push yet, follow the user's instruction instead.
